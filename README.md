# Excel Date Functions Practice 📊

This project contains my practice work with important Excel date functions.

## Functions Covered

### 1. DATE()

Used to create a date from separate Year, Month, and Day values.

**Example:**

```excel
=DATE(2026,9,10)
```

### 2. TEXT()

Used to convert a date or number into a specific text format.

**Examples:**

```excel
=TEXT(A2,"DD-MM-YYYY")
=TEXT(A2,"MMMM YYYY")
```

### 3. DATEDIF()

Used to calculate the difference between two dates in years, months, or days.

**Examples:**

```excel
=DATEDIF(A2,B2,"Y")
=DATEDIF(A2,B2,"M")
=DATEDIF(A2,B2,"D")
```
